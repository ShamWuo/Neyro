# NEYRO — COMPREHENSIVE DEMO BUILD SPEC
## For AI Agent Execution | Next.js | Demo Mode

---

## OVERVIEW

This document specifies every screen, component, interaction, and piece of copy needed to build a fully functional Neyro demo. Demo mode means: pre-seeded with realistic data, all AI responses are simulated via a local mock layer (no live API calls required), and every core loop is completable end-to-end by a stranger in under 5 minutes.

**Stack:** Next.js (App Router), TypeScript, Tailwind CSS, Zustand (state), Framer Motion (animations)
**AI Layer:** Mock service — deterministic responses based on input keywords, no real API calls needed for demo
**Data:** Local Zustand store seeded with demo data on first load
**Auth:** Skip entirely — demo opens directly to the main dashboard

### Classification Logic (Mock AI Rules)
The demo AI mock should classify based on these keyword rules:

```typescript
// Mock classification logic
function classifyInput(text: string): PARACategory {
  const lower = text.toLowerCase();
  
  // Projects: deadline words, action + goal words
  if (/finish|complete|build|launch|create|deadline|by (monday|tuesday|wednesday|thursday|friday|saturday|sunday|jan|feb|mar|next week)|due|ship|deliver/.test(lower)) {
    return 'projects';
  }
  
  // Areas: ongoing responsibility words
  if (/health|fitness|workout|exercise|finance|budget|money|savings|relationship|family|friend|career|work|job|learning|habit|routine|weekly|monthly/.test(lower)) {
    return 'areas';
  }
  
  // Resources: reference, ideas, information
  if (/article|read|research|idea|note|reference|link|book|learn|interesting|thoughts on|how to|guide|template/.test(lower)) {
    return 'resources';
  }
  
  // Default: projects (most common capture intent)
  return 'projects';
}

function classifyReason(text: string, category: PARACategory): string {
  const reasons = {
    projects: "I detected a goal with a clear outcome — this has a finish line.",
    areas: "This sounds like an ongoing responsibility, not a one-time task.",
    resources: "This looks like reference material you'll want to come back to.",
    archive: "This seems complete or no longer active."
  };
  return reasons[category];
}
```
