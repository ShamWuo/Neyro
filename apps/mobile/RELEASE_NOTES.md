# Neyro V2 - Release Notes

## Version 2.0.0 - "Psychic AI"

### 🧠 Intelligent Inbox
**AI that explains itself**
- See why the AI classified each item with reasoning and confidence scores
- Automatic action chunking: "Buy milk, call mom, finish essay" → 3 separate tasks
- Smarter project/area matching based on context

### 📊 Project Health System
**Never let projects go stale**
- Visual health indicators (🟢 Active → 🔴 Stale)
- Automatic staleness detection (7+ days inactive)
- Deadline warnings and overdue alerts
- Faded opacity for neglected projects

### 💪 Area Health Scoring
**Life areas that demand attention**
- Dynamic 1-5 health scores based on real activity
- Tracks tasks completed and focus time invested
- "Needs attention" alerts for neglected areas
- Operationalizes the PARA method

### 🎨 UX Improvements
- Natural language date parsing ("tomorrow", "next Friday")
- Cleaner inbox UI with better spacing
- Improved bottom navigation
- Enhanced visual feedback

### 🔧 Under the Hood
- 97% test coverage
- Improved AI prompts for better classification
- Optimized database queries
- Better error handling
