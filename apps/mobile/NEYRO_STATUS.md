# Neyro - Project Status

## Overview
**Neyro** is a decision-forcing productivity system built around CODE (Capture, Organize, Distill, Express) and PARA (Projects, Areas, Resources, Archive).

**Goal**: Force clarity and completion by limiting active projects and enforcing weekly reviews.
