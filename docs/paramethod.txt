PARA Method: The Definitive Guide for Neyro
1. Executive Summary
The PARA Method is a universal system for organizing digital information, pioneered by Tiago Forte (Building a Second Brain). Unlike traditional systems organized by subject (e.g., "Architecture," "Marketing"), PARA is organized by actionability.

The core philosophy is: "We don't organize information to store it; we organize it to use it."

2. The Four Categories
Information is classified into one of four folders based on its current level of activity.

1. Projects (P)
Definition: A series of tasks linked to a goal with a specific deadline.

Key Traits: Short-term, high-effort, and has a clear "Done" state.

The Neyro Constraint: Maximum of 7 active projects to prevent cognitive overload.

Examples:

Complete Neyro Landing Page v1.0 (Due Friday)

Plan Q3 Marketing Budget

Write "Deep Work" Blog Post

2. Areas (A)
Definition: A sphere of activity with a standard to be maintained over time.

Key Traits: No end date. These are ongoing responsibilities.

Examples:

Health: Diet, gym, sleep tracking.

Finances: Savings, taxes, bills.

Professional: Skill development, management, networking.

3. Resources (R)
Definition: A topic or theme of ongoing interest.

Key Traits: "Interesting but not urgent." These are libraries of references, research, or inspirations that could be useful for future projects.

Examples:

CSS Typography Snippets

Recipes for Meal Prep

Psychology of Productivity notes

4. Archives (A)
Definition: Completed or inactive items from the other three categories.

Key Traits: "Frozen" data. It is kept for historical reference but is removed from the daily view to reduce clutter.

Examples:

Completed Projects

Areas you are no longer responsible for

Resources that are no longer relevant

3. The PARA Flow (The "Neyro" Workflow)
Neyro enforces the dynamic movement of data through these four stages:

Capture: Everything starts in the Inbox. Frictionless entry.

Organize: Using the "Smart Assist," items are moved to P, A, or R.

Finish: Active focus remains on Projects.

Ship/Archive: Once a project is finished, it is moved to Archives to make room for a new project.

4. Why This Works (Scientific Principles)
Zeigarnik Effect
The brain remembers uncompleted tasks better than completed ones, causing "mental loops." PARA closes these loops by giving every item a designated "home" based on when it will be used.

Cognitive Load Theory
By limiting Projects to seven, Neyro prevents the "Paradox of Choice." When everything is a priority, nothing is a priority.

Production vs. Consumption
Most apps encourage "digital gardening" (organizing for fun). PARA encourages "Shipping." If an item doesn't support a Project, it is moved down the hierarchy to keep the workspace clean.
