# Product Roadmap

Strategic plan for Neyro's development, growth, and monetization.

## 🚀 Phase 1: Launch Readiness (Immediate)
**Goal:** First 100 Active Users

### Critical Infrastructure
- [ ] **Stripe Integration**
  - [ ] Checkout flow & webhook with subscription enforcement.
  - [ ] Billing portal for self-service cancellation/upgrades.
- [ ] **Subscription Gates**
  - [ ] Enforce 7-project limit for free users.
  - [ ] AI credit system (50 credits/mo free, unlimited paid).
- [ ] **Email System**
  - [ ] Setup Resend/Postmark.
  - [ ] Implement welcome sequence & weekly review reminders.

### Viral Core
- [ ] **Shareable Weekly Review**
  - [ ] Generate "My Week in Review" image card.
  - [ ] "Share" button on review summary page.
- [ ] **Referral System**
  - [ ] Unique user referral codes.
  - [ ] Reward logic (1 mo free for both parties).

---

## 📈 Phase 2: Growth Engine (Months 2-3)
**Goal:** $3k MRR

### Growth Features
- [ ] **Project Public Showcase**: Read-only public view for sharing projects.
- [ ] **Template Marketplace**: Community-shared project templates.
- [ ] **Team Workspaces**: "Brain Trust" tier features for shared resources.

### User Retention
- [ ] **Mobile PWA Enhancements**: Offline mode, push notifications.
- [ ] **Gamification**: Review streaks, "Inbox Zero" celebrations.
- [ ] **Integrations**: Google Calendar two-way sync.

---

## 🛠️ Phase 3: Scale & Enterprise (Months 4-6)
**Goal:** $10k MRR

### Advanced Features
- [ ] **Native Mobile Apps**: Publish iOS/Android versions via Capacitor.
- [ ] **Voice 2.0**: Conversational AI assistant for capture/review.
- [ ] **Analytics**: Long-term productivity trends and insights.

### Platform Hardening
- [ ] **Enterprise Security**: SSO, Audit Logs.
- [ ] **Performance**: Redis caching, CDN optimization.
- [ ] **Localization**: Multi-language support.

---

## ✅ Completed (2025)
- **Core PARA System**: Projects, Areas, Resources, Archive fully functional.
- **AI Classification**: Google Gemini integration for seamless capture.
- **Voice Input**: Web Speech API integration.
- **Security Hardening**: Rate limiting, XSS protection, input validation.
- **Visual Polish**: Dark mode, consistent theming, responsive UI.
